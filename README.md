# MINDS4MOTION — Official Website

**Think. Feel. Create.**  
`#justcreative`

A static, responsive website for MINDS4MOTION. The design follows the established visual language: reduced, intentional, black / white / red, with no decorative excess.

## Baseline

**Current baseline: v1.0 — Initial website (16 November 2026).** See [VERSION.md](VERSION.md).

## Files
- `index.html` — complete public website (HTML, CSS and minimal JavaScript)
- `VERSION.md` — v1.0 baseline and scope
- `.github/workflows/pages.yml` — manually triggered GitHub Pages deployment

## Publishing with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Set **Build and deployment → Source: GitHub Actions**.
3. Go to **Actions → Publish MINDS4MOTION Website → Run workflow** on `main`.
4. Verify the published page after the workflow completes.

The workflow is deliberately manual. A normal push or merge does **not** publish automatically.

## Privacy / security
- No analytics or tracking
- No cookies
- No backend
- No forms or payment collection
- Contact email is assembled only when the contact button is clicked (basic deterrent against simple HTML scrapers)

## Separation
This repository is public and intentionally contains only the MINDS4MOTION website and its publishing workflow. Private M60 OS material, personal records, private family/legal information and internal project documents must never be copied into this repository.
