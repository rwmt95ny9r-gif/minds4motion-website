# MINDS4MOTION Website — v1.0

**Baseline:** 16 November 2026  
**Status:** initial public-website baseline, prepared for GitHub Pages  
**Repository target:** `rwmt95ny9r-gif/minds4motion-website`

## Scope

- Responsive, English-language static website
- MINDS4MOTION wordmark treatment with red `4`
- Core line: **Think. Feel. Create.**
- Core hashtag: **#justcreative**
- Brand idea: making what moves us visible
- Manifesto around thinking, feeling and creating
- Four personal/creative worlds:
  - 🥷 🔥 🇯🇵 — Fight / drive
  - ❣️ 🐅 ⚽️ — Family / presence
  - ❤️ 🇮🇹 🏝️ — Love / Italy / sea
  - ☀️ 🇸🇪 🏔️ — Joy / Lagom / mountains
- Creative-language section for visual work, music, series and reduction
- Selected musical references reflecting the established MINDS4MOTION sound
- Personal "Behind MINDS4MOTION" section without exposing private biographical or family details
- Instagram link and basic-obfuscated contact link to `md@minds4motion.com`
- No external libraries, tracking, cookies, forms or backend

## Design rules

- Primary palette: black, white and MINDS4MOTION red
- Reduced, clean, intentional
- No decorative kitsch or artificial "AI beauty"
- High-contrast typography, generous negative space
- Visual tension through scale and red accents rather than background effects

## Deployment

- GitHub Pages via `.github/workflows/pages.yml`
- Workflow runs manually (`workflow_dispatch`)
- Only the public website content is published

## Boundaries

The public site expresses the MINDS4MOTION creative identity. It deliberately excludes private Project Michael / M60 information that is not part of the public brand narrative, including personal family, legal, financial, health or employer-internal material.
